Iso-PPL remaining-params law

Closed form for remaining nonzero parameters at fixed absolute perplexity, fit on Qwen3.5 SparseGPT (C4 calibration).

How to read the plot. Each colored curve is one fixed perplexity P*. Points on that curve are different model sizes (0.8B → 2B → 4B → 9B → 27B), not repeats of the same model. Moving right along a curve = larger model, higher sparsity, but also higher remaining params R — so not sparse-optimal.

Definition

ln(P*/P0(N)) = α · N^β · s^b s(N,P*) = [ln(P*/P0(N)) / (α · N^β)]^(1/b) R(N,P*) = N · (1 − s)

Dense baseline fit separately as P0(N) = A + B · N^g. Sparse-optimality fails when ∂R/∂N > 0 (equivalently γ > 0 in R ∝ N^γ).
